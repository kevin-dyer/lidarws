FAST-LIVO2 INTEGRATION SUMMARY
================================================================================

PROBLEM:
--------
FAST-LIVO2 expects specific ROS 2 topic names and message types from a 
Livox LiDAR driver, but your 3D scanner + mobile app publishes to different 
topics:
  Mobile Bridge:          FAST-LIVO2 Expects:
  /lidar/points      →    /livox/lidar
  /imu/data          →    /livox/imu
  /camera/image_raw  →    /left_camera/image

SOLUTION:
---------
Created a lightweight topic adapter that republishes your mobile bridge 
data to the correct FAST-LIVO2 topic names without modifying either system.

NEW FILES CREATED:
------------------
1. lidar_ros2_bridge/fast_livo_adapter.py
   - Simple node that subscribes to mobile bridge topics
   - Republishes to FAST-LIVO2 topics
   - Zero latency overhead (direct message pass-through)

2. lidar_ros2_bridge/launch/fast_livo_mobile.launch.py
   - One-command launch for entire pipeline
   - Starts: mobile bridge + adapter + FAST-LIVO2 + RViz2
   - Configurable mobile IP and RTSP URL

3. FAST_LIVO2_INTEGRATION.md
   - Complete setup and usage guide
   - Troubleshooting section
   - Data format reference

4. FAST_LIVO2_TOPIC_MAP.md
   - Detailed topic specifications
   - Data flow diagram
   - Configuration tuning guide

5. FAST_LIVO2_QUICK_COMMANDS.sh
   - Quick reference for common tasks
   - Pre-formatted commands to copy/paste

QUICK START:
------------
# Build (one-time)
cd ~/dev/lidarws && colcon build --packages-select lidar_ros2_bridge lvi_sam_mobile
cd ~/dev/ros2_fast_livo_ws && colcon build --packages-select fast_livo

# Source both workspaces
source ~/.bashrc  # if both are in your .bashrc

# Launch everything
ros2 launch lidar_ros2_bridge fast_livo_mobile.launch.py \
  mobile_ip:=192.168.1.100 \
  use_rviz:=True

# Verify data flow
ros2 topic hz /livox/lidar
ros2 topic hz /livox/imu
ros2 topic hz /left_camera/image

ARCHITECTURE:
--------------
Mobile Device
    ↓ (UDP: LiDAR, IMU | RTSP: Camera)
Mobile Bridge (your existing system)
    ↓ /lidar/points, /imu/data, /camera/image_raw
Topic Adapter (NEW: simple republisher)
    ↓ /livox/lidar, /livox/imu, /left_camera/image
FAST-LIVO2 (existing workspace)
    ↓ (outputs: /tf, /odom, /cloud_pcd)
RViz2 Visualization

KEY ADVANTAGES:
---------------
✓ No modifications to mobile bridge code
✓ No modifications to FAST-LIVO2 code
✓ Zero latency overhead (direct message forwarding)
✓ Keeps both systems independent and easy to debug
✓ Can run other LVI-SAM pipelines alongside FAST-LIVO2
✓ Easy to disable/enable with launch argument
